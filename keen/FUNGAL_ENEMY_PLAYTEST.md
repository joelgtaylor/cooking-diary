# Fungal enemy pilot

Opt-in only: `fungal=pilot`. Main remains unchanged pending playable review.

Scenes: `scene=fungal-flight` (Sporewing at the entrance), `fungal-opening` (Cap Walker), `fungal-hopper` (Springcap), `fungal-caster` (Spore Caster). Each starts paused on real authored support, without granting cultures, solving puzzles or writing saves. `fungal=off` compares original ground artwork with no added flyer. Reload resets the scene. Normal gameplay progression remains available.

All eight existing Bakery 2 enemies use approved fungal identities. Their bounds, positions, health, rewards and projectile rules remain identical. Walk/hop timing is unchanged; the pilot caster now uses a30-tick ready/reacquisition minimum,24-tick wind-up and84-tick post-shot delay. Springcap compresses in the last ten supported countdown ticks. Spore Caster release/recovery is keyed to actual projectile creation. Its pearl is a visual reskin of the same 9×9 horizontal shot. Fallbacks preserve original ground art during loading/failure.

One new Sporewing patrol is introduced before the original opening walker: x32–256, altitude1600, 25×25 contact body, 1.1px/tick horizontal patrol. It waits90ticks initially, warns24ticks when an unobstructed player is below, then snapshots an aimed dive with a small capped movement lead at release (about7px/tick), brakes24ticks and returns at2px/tick, then waits120ticks. A dive does not home after release; changing course dodges it. The return travels back toward the launch position and patrol altitude. Solids/one-way support shelter the player and stop descent. No new sound effects. Shoot or descending mixer pogo defeats it in one hit with existing ordinary-enemy rewards; contact uses existing damage/shield/invulnerability. A living flyer resets to patrol on checkpoint recovery; defeated ordinary enemies remain defeated as before.

Production atlases: `art/fungal-enemies.png` and `art/sporewing.png`, 1536×1024 RGBA, generated with the built-in image tool from approved concepts. No raster post-processing; immutable source crops in `fungal-enemies.js`. Ground identity prompt: approved Cap Walker/Springcap/Spore Caster in three rows of four walk/compress/launch/aim/release/recovery poses, transparent background. Flyer prompt: approved Sporewing in two rows of four wingbeat/warn/dive/brake/return poses; spacing revised for isolated rectangular crops.

Validation: 308 game/audio tests pass, including opt-in/world exclusion, real supported scene spawns, 900-tick walker/hopper simulation equivalence, warning/target lock, cover and offscreen gating, support impact, bounded patrol, one-hit defeat/contact damage, render purity, crop bounds and retry reset. The prior build was browser checked for all roles. Follow-up tuning adds tests for stationary/steady-walking hits, post-release dodging and exact caster shot cadence. Real-device touch playtesting remains part of user review.

Bloomrot, other bosses, flags, soundtrack, authored geometry, puzzle state and Bakery1/3 enemies are unchanged. Further flyer placements and tuning require review.
